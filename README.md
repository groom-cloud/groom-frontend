## 📌 주요 특징

- **01~08 표준 엔지니어링 라이프사이클**:
  - `01 서비스 기획 & BM`: 핵심 문제 정의, 양면 시장 모델, 수익화 전략 구조화
  - `02 요구사항 명세 (PRD)`: 우선순위(P0~P2), 기능/비기능 제약, 인수 조건
  - `03 화면 흐름 & UI/UX`: 캔버스 기반 인터랙티브 화면 동선 및 화면 간 연결선
  - `04 데이터베이스 설계 (ERD)`: 엔티티 다이어그램, 테이블 관계선, PostgreSQL DDL 스키마
  - `05 시스템 아키텍처 토폴로지`: VPC, Subnet, Spring Boot, DB, Cache, SSE 인프라 시각화
  - `06 WBS & 칸반 보드`: 스프린트 일정 관리, 상태 드래그앤드롭 트래킹
  - `07 개발 명세 & API 가이드`: OpenAPI JSON 규격, Git 브랜치 전략, Cursor AI 프롬프트
  - `08 운영 & 트러블슈팅 아카이빙`: 배포 타임라인, 롤백 런북, 정량적 성능 개선 일지

- **4대 서비스 도메인 스택 최적화**:
  - 웹 서비스 (React + Spring Boot + PostgreSQL + Redis)
  - 모바일 앱 서비스 (Flutter / React Native + Supabase)
  - AI 에이전트 & 데이터 (FastAPI + LangChain + Vector DB)
  - 게임 클라이언트 & 백엔드 (Unity / Unreal + Go Server)

- **유연한 파이프라인 트랙**:
  - 전문가 트랙 (8단계 전체) / 초보자 패스트트랙 (4단계) / 커스텀 플로우 지원

- **모바일 & 데스크톱 반응형 캔버스**:
  - 무한 캔버스 패닝, 줌 인/아웃, 핀치 줌, 노드 이동 및 연결 지원

## 🚀 빠른 시작

### 1. 패키지 설치
```bash
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm run dev
```

### 3. 프로덕션 빌드
```bash
npm run build
```

- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, OKLCH 테마 시스템 (Apple HIG & Calm Design)
- **Icons**: Lucide React
- **Typography**: Pretendard Variable, JetBrains Mono
